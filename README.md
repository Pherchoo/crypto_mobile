# Crypto Mobile

Aplicación Expo con React Native y JavaScript (JSX).

- `App.jsx`: entrada de la aplicación.
- `src/App.jsx`: pantalla principal.
- `src/components/`: componentes JSX.
- `src/styles/`: estilos nativos con StyleSheet (React Native no importa CSS web).

## Ejecutar

```bash
npm install
npm start
```

Abre el proyecto en un dispositivo o emulador compatible con el SDK de Expo instalado.

## Verificar

```bash
npm run lint
npm run typecheck
```

TypeScript se mantiene como herramienta para comprobar el JavaScript; el código de la aplicación usa `.js` y `.jsx`.
